# پورتفولیو ساز — Portfoilo Builder

استودیوی فارسی و راست‌چین برای ساخت پورتفولیو، الهام‌گرفته از رابط بنفش و آبی مرجع پروژه.

## امکانات نسخه ۱

- ویزارد چهارمرحله‌ای: مشخصات و مهارت‌ها، پروژه‌ها، قالب و پالت، دامنه و خروجی.
- شش قالب مرجع کدکرفت، اورگرین، کورال، آمتیست، لرن‌هاوس و ادوویولت؛ شش پالت رنگ.
- پیش‌نمایش زنده، نمای موبایل و بزرگ‌نمایی.
- تصویر پروفایل و تصاویر پروژه با کوچک‌سازی محلی؛ حداکثر ۱۲ پروژه.
- پیش‌نویس محلی خودکار، خروجی و بازیابی JSON، اطلاعات نمونه با تأیید جایگزینی.
- خروجی HTML کامل و مستقل با تصاویر داخلی، متادیتا و طراحی واکنش‌گرا.
- ورود GitHub OAuth و ذخیره JSON هر کاربر در مخزن خصوصی جداگانه؛ کنترل مالکیت بر اساس شناسه تأییدشده گیت‌هاب.
- کنترل تداخل نسخه برای جلوگیری از بازنویسی ناخواسته داده، محدودیت حجم و نرخ درخواست، کوکی HttpOnly، SameSite و کنترل Origin.

## اجرای سریع

نیازمندی: Node.js 22 یا بالاتر. برنامه وابستگی npm ندارد.

```sh
npm start
```

سایت در `http://localhost:3000` اجرا می‌شود. بدون متغیرهای محیطی، ویزارد، تصاویر، پیش‌نمایش، پشتیبان و خروجی مستقل کار می‌کنند؛ دکمه ورود حالت محلی را نشان می‌دهد.

```sh
npm run check
npm test
```

## فعال‌کردن ورود و ذخیره آنلاین

کد برنامه می‌تواند عمومی باشد؛ **داده کاربران نباید در همین مخزن عمومی قرار بگیرد**. سرور عمداً نوشتن و خواندن داده از مخزن عمومی را رد می‌کند.

1. یک مخزن **Private** مخصوص داده بسازید. یک README اولیه اضافه کنید.
2. یک GitHub OAuth App بسازید. Homepage برابر دامنه برنامه و Callback برابر `https://YOUR-BUILDER-DOMAIN/auth/callback` باشد.
3. `.env.example` را به `.env` کپی و متغیرها را تکمیل کنید. در هاست از بخش Secrets/Environment استفاده کنید.
4. `GITHUB_DATA_TOKEN` یک fine-grained token فقط برای همان مخزن داده با Contents read/write و Metadata read باشد. `GITHUB_CLIENT_SECRET` و توکن هرگز در مرورگر یا git قرار نمی‌گیرند.
5. `SESSION_SECRET` دست‌کم ۳۲ نویسه تصادفی باشد. `APP_ORIGIN` باید دقیقاً origin سایت، بدون اسلش انتهایی، باشد.
6. پس از راه‌اندازی دوباره سرور، ورود گیت‌هاب و دکمه ذخیره مرحله آخر فعال هستند.

ساختار داده: `portfolios/<verified-github-user-id>/profile.json`. اطلاعات و تصاویر کوچک‌شده داخل همین JSON هستند. هیچ شناسه کاربری از ورودی مرورگر برای انتخاب مسیر پذیرفته نمی‌شود. در هر حساب یک پورتفولیو ذخیره می‌شود. ابتدا برای ویرایش رکورد موجود «بازیابی از حساب من» را بزنید. در برخورد نسخه‌ها ابتدا از پیش‌نویس پشتیبان بگیرید.

## دامنه و انتشار

نام دامنه در مرحله چهارم ثبت و اعتبارسنجی می‌شود، اما ثبت نام، خرید یا اتصال DNS خودکار نیست. خروجی HTML را با نام `index.html` در ریشه هاست یا یک static host قرار دهید؛ دامنه و HTTPS را مطابق پنل همان میزبان تنظیم کنید. برنامه سازنده به هاست Node.js یا Docker نیاز دارد؛ GitHub Pages برای بخش سرور و ذخیره آنلاین کافی نیست. رمز پنل دامنه از کاربر دریافت نمی‌شود.

```sh
docker build -t portfoilo-builder .
docker run --env-file .env -p 3000:3000 portfoilo-builder
```

## حدود فعلی

این نسخه پایه قابل اجراست. انتشار خودکار برای هر کاربر، خرید دامنه، اتصال DNS، بازیابی رمز و پرداخت در آن وجود ندارد. OAuth فقط گیت‌هاب است. نشست‌های ورود در حافظه فرایند نگهداری می‌شوند؛ با ری‌استارت ورود مجدد لازم است و برای چند replica باید session store مشترک اضافه شود. مخزن گیت‌هاب برای تعداد کم کاربران مناسب است؛ تعداد زیاد کاربران و تصاویر به ذخیره‌ساز و پایگاه‌داده اختصاصی نیاز دارد. حذف یا اصلاح داده در آخرین commit، تاریخچه git را پاک نمی‌کند. پیش‌نویس مرورگر دستگاه مشترک خصوصی محسوب نمی‌شود.

تست‌ها اعتبارسنجی، خروجی HTML، جلوگیری از تزریق، مسیرهای سرور و کنترل Origin را پوشش می‌دهند. اتصال زنده OAuth/مخزن داده و دامنه باید پس از تنظیم Secrets در محیط مقصد آزموده شود.

## طراحی نسخه ۳ — شش مرجع ارسالی

قالب‌های قبلی حذف شده‌اند. شناسه قدیمی در پیش‌نویس‌ها به کدکرفت تبدیل می‌شود؛ مشخصات و پروژه‌ها حفظ می‌شوند. صفحه اصلی مستقل در `/` و ویزارد در `/builder` است.

| شناسه | مرجع | ساختار |
| --- | --- | --- |
| codecraft | توسعه‌دهنده تیره | پرتره با هاله بنفش، کارت کد، شبکه مهارت‌ها، پروژه‌ها |
| evergreen | خانه در طبیعت | هیروی کاور، نوار شناور زیتونی، معرفی دو ستونی، کارت پروژه |
| coral | طراح هلویی | پرتره دایره‌ای، کارت شیشه‌ای ارتباط، نمونه‌کارهای سه ستونی |
| amethyst | متخصص یاسی | پرتره قدی، کارت آمار از داده واقعی، خدمات آیکون‌دار، معرفی |
| learnhouse | مربی سبزآبی | هیروی سبزآبی، دکمه زرد، لبه منحنی، خدمات قاب‌دار، مسیر حرفه‌ای |
| eduviolet | آموزش بنفش‌صورتی | قاب خط‌چین، کارت‌های شناور، نوار مهارت، پروژه‌ها در گرادیان |

فونت واقعی **Vazirmatn** با وزن معمولی و ضخیم به صورت WOFF داخلی استفاده شده است. فایل خروجی هم فونت و مجوز OFL را همراه دارد. کاور، تیتر اصلی و فهرست خدمات در ویزارد قابل ورود هستند. رنگ پیش‌فرض هر قالب از مرجع گرفته شده؛ انتخاب دستی پالت آن را تغییر می‌دهد. تغییر قالب رنگ بومی آن را برمی‌گرداند.

تصاویر مرجع برای چیدمان و سبک استفاده شدند؛ تصاویر اشخاص و شرکت‌ها، لوگوهای مشتریان، نظرات و آمار تبلیغاتی آن‌ها به نام کاربر درج نمی‌شوند. تصاویر واقعی پورتفولیو از بارگذاری‌های کاربر می‌آیند؛ جای خالی آن‌ها با طرح گرافیکی پر می‌شود. قالب آموزشی در این نسخه ارائه تخصص و پروژه است، نه سامانه فروش دوره.

بررسی‌های خودکار شامل شش قالب جدید، فونت داخلی، حفظ فیلدهای پشتیبان، ناوبری داخلی، اعتبارسنجی و مسیرهای سرور است. بررسی بصری مرورگر در این محیط تأیید نشده است.
